# 1. Sitemap และโครงสร้างเมนู

```
หน้าแรก (#/)
├─ เกี่ยวกับสหกรณ์ (#/about)
│  ├─ ประวัติสหกรณ์            #/about/history
│  ├─ วิสัยทัศน์ – พันธกิจ       #/about/vision
│  ├─ คณะกรรมการดำเนินการ      #/about/board
│  ├─ ผู้ตรวจสอบกิจการ          #/about/auditors
│  ├─ เจ้าหน้าที่               #/about/staff
│  └─ ผังองค์กร                #/about/org
├─ บริการ
│  ├─ บริการเงินฝาก            #/deposit      (ประเภทบัญชี, ตารางดอกเบี้ย, เงื่อนไข)
│  ├─ บริการเงินกู้             #/loan         (ประเภท, คุณสมบัติ, เอกสาร, วงเงิน)
│  ├─ คำนวณค่างวดเงินกู้         #/calculator   (ลดต้นลดดอก / ผ่อนคงที่ / เปรียบเทียบ)
│  └─ สวัสดิการสมาชิก           #/welfare
├─ ข่าวและประกาศ               #/news  → #/news/:id
│     หมวด: ประกาศทั่วไป · ประชุมใหญ่ · เลือกตั้ง · ปันผล-เฉลี่ยคืน · สวัสดิการ  (ค้นหา, ปักหมุด, PDF, แบ่งหน้า)
├─ ดาวน์โหลด                   #/downloads    (แบบฟอร์ม 4 หมวด · ระเบียบ · ข้อบังคับ + ค้นหา)
├─ เปิดเผยข้อมูล                #/disclosure   (KPI, กราฟ 5 ปี, งบการเงิน, รายงานประจำปี)
├─ ติดต่อเรา
│  ├─ ติดต่อ / ร้องเรียน         #/contact      (ที่อยู่ แผนที่ เวลาทำการ โทร LINE + ฟอร์ม)
│  ├─ คำถามที่พบบ่อย            #/faq          (accordion + ค้นหา)
│  └─ นโยบายความเป็นส่วนตัว      #/privacy      (PDPA + ตั้งค่าคุกกี้)
├─ ผังเว็บไซต์                  #/sitemap
│
├─ ระบบสมาชิก (ต้องเข้าสู่ระบบ: เลขทะเบียน + รหัสผ่าน + OTP)   #/member
│  ├─ ภาพรวม            #/member/overview
│  ├─ ทุนเรือนหุ้น        #/member/shares
│  ├─ เงินฝาก            #/member/deposits      (ทุกบัญชี + รายการเคลื่อนไหว)
│  ├─ เงินกู้             #/member/loans         (คงเหลือ, ตารางผ่อน, งวดคงเหลือ)
│  ├─ ภาระค้ำประกัน       #/member/guarantees    (ค้ำให้ใคร / ใครค้ำให้)
│  ├─ ใบเสร็จรับเงิน       #/member/receipts → #/member/receipt/:YYYY-MM (ดู/พิมพ์/PDF)
│  ├─ ปันผล/เฉลี่ยคืน      #/member/dividends
│  ├─ ผู้รับผลประโยชน์      #/member/beneficiaries
│  └─ เปลี่ยนรหัสผ่าน       #/member/password
│
└─ ระบบผู้ดูแล (เจ้าหน้าที่)   #/admin
   ├─ แดชบอร์ด · ข่าว/ประกาศ · แบนเนอร์ · อัตราดอกเบี้ย · ไฟล์ดาวน์โหลด · คณะกรรมการ · FAQ
   ├─ เรื่องร้องเรียน · นำเข้าสมาชิก (CSV / เชื่อมระบบหลัก)
   └─ ผู้ใช้และสิทธิ์ (Super Admin / เจ้าหน้าที่ / ผู้ดูข้อมูล) · Audit log
```

**เมนูหลัก (Desktop ≥1100px):** หน้าแรก · เกี่ยวกับสหกรณ์ ▾ · บริการ ▾ · ข่าวและประกาศ · ดาวน์โหลด · เปิดเผยข้อมูล · ติดต่อเรา ▾ · [ปุ่มทอง: ตรวจสอบข้อมูลสมาชิก]
**มือถือ:** โลโก้ + ปุ่มสมาชิก + ☰ → Drawer ด้านขวา (เมนูย่อยเป็น accordion, ปุ่มโทรด่วน)
**แถบบนสุด:** เวลาทำการ · เบอร์โทร · LINE · ปรับขนาดตัวอักษร ก-/ก/ก+ · สลับโหมดมืด
